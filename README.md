# 2526_0487_demo_UnitTesting

## Descripció
Aquest projecte està creat amb **Kotlin** i està pensat com a material educatiu per ajudar els alumnes a aprendre i millorar les seves habilitats en:
- Treball amb funcions
- Creació i execució de tests unitaris

L'objectiu és proporcionar una introducció pràctica a la implementació i verificació del codi mitjançant proves unitàries (unit testing), assegurant així que el codi compleixi els requisits i funcioni com s'espera.

## Llenguatges utilitzats
Aquest projecte, tot i tenir diverses tecnologies, està pensat per a l'aprenentatge fent servir Kotlin:
- **Kotlin**: 35% del codi
- **HTML**: 27,2%
- **JavaScript**: 22%
- **CSS**: 15,8%

## Com començar
1. Clona el repositori mitjançant el teu IDE preferit (recomanem IntelliJ IDEA).
2. Assegura't de tenir el JDK instal·lat (Java Development Kit) per tal d'executar el projecte Kotlin.

## Executant els tests
1. Ves a la carpeta on es troben els tests dins del projecte (/src/test/kotlin/).
2. Executa'ls directament des de l'entorn integrat.
